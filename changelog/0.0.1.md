# 0.0.1（首次打包）

日期：2026-11-26

## 项目说明

本项目是基于 [travisvn/openai-edge-tts](https://github.com/travisvn/openai-edge-tts)
修改而来的 OpenAI 兼容 TTS 服务，底层使用 Microsoft Edge TTS。

## 首次打包内容

- `app/`：服务源码
- `Dockerfile`：精简后的镜像构建文件
- `docker-compose.yml`：Docker Compose 编排文件
- `.env`：环境变量配置文件
- `README.md`：项目说明、部署方式、使用方法和兼容信息
- `changelog/`：版本更新记录目录
- `images/`：镜像归档保存目录

## 当前版本功能

- OpenAI 兼容的 `POST /v1/audio/speech` TTS 接口
- `GET /v1/models` 标准模型列表接口
- `GET /v1/voices` 音色列表接口
- 支持 `mp3` / `wav` / `opus` / `aac` / `flac` / `pcm`
- 支持 SSE 流式输出
- 兼容 ElevenLabs 和 Azure TTS 的核心接口
- 内置 FFmpeg，非 Docker 环境无系统 FFmpeg 时仍可输出多种格式
- 内置限流、排队、熔断、重试和临时文件清理

## 相对上游项目的修改

- 固定 `edge-tts==7.3.1`，解决微软侧 `403` 问题
- 使用 `imageio-ffmpeg` 内置静态 FFmpeg，减小镜像体积
- `/v1/models` 改为标准 OpenAI 返回格式：
  `object: list` + `data` 对象数组，不再额外返回 `models` 字段
- 新增 `TTS_MODELS` 环境变量，控制暴露的模型 ID
- 增加 `loop.shutdown_asyncgens()`，减少退出时的 aiohttp/asyncio 告警
- `Dockerfile` 内联依赖列表，不再依赖单独的 `requirements.txt`
- 镜像名和容器名统一为 `edge-tts-openai`
- 配置使用 `.env` 文件，并带中文注释
- 移除 `1panel-network` 外部网络配置
